# xinggui-public

星轨「检查更新」用的公开清单仓库。这里**只放版本清单**，不含源码。

- `latest.json` — 客户端启动时拉取，用于判断是否有新版本
- 源码在私有仓库，不对外开放

字段说明：

| 字段 | 含义 |
|---|---|
| version | 最新版本号（语义化，如 0.2.0） |
| channel | 通道：stable / beta |
| releasedAt | 发布日期 |
| url | 安装包下载地址 |
| sha256 | 安装包哈希，客户端下载后校验 |
| size | 字节数 |
| notes | 更新说明，数组，每条一行 |
| minVersion | 低于此版本必须强制更新 |
